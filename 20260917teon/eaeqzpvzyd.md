# 世界提高抗微生物药物认识周丨抗生素合理应用

> 更新时间：2026-09-17 (UTC+8)

“
 
医疗领域如何掌握抗生素治疗上的正确使用？

1

//

严格掌握适应症，诊断为细菌感染者才使用抗生素。病毒感染、无感染征象的发热都不是抗生素的应用指征。

2

//

有条件的尽量做培养和药敏试验，条件不允许的凭经验选择可能对致病菌敏感的药物，避免长时间大剂量的应用广谱抗生素。

3

//

抗生素种类根据病情，能口服用药的尽量选择口服，最后才选择静脉用药。一般轻者口服或肌注，病情较重者可选用1种静注，危重患者遵医嘱可联合应用2或3种抗生素。

4

//

联合应用抗菌药物必须有明确的指征，应该避免联用毒性反应有叠加、相互间疗效产生影响或同一类型的药物。比如青霉素G与红霉素联用，疗效反而会降低。

5

//

严格掌握广谱抗生素应用的剂量和时间，私自减少用药次数或用药量非但不能有效发挥疗效，还会使致病菌易产生耐药性。

6

//

警惕药物过敏史，应仔细阅读说明书或者遵医嘱。

7

//

特殊人群慎用，对儿童、老人、孕妇及肝肾功能不良的这一类特殊患者来说，应仔细阅读说明书或遵从专业医务人员的帮助，以避免不良反应的发生和诱发原有的疾病。

8

//

食物的影响：一些碱性食物如苏打饼干、啤酒会增强红霉素的疗效，同时另一些食物如葡萄柚、柳橙汁也能降低红霉素的疗效。使用头孢类抗菌药物期间严禁饮酒，甚至在使用上述抗菌药期间及停药后14天内，均应避免饮酒或进食含酒精制品。

9

//

药物的影响：如青霉素有不能与碳酸氢钠配伍的禁忌；大环内酯类、抗真菌药物多是肝药酶的抑制剂，与其联用的其他抗生素药效增强，也可使副作用增多；苯妥英钠、苯巴比妥、西咪替丁等则是肝药酶诱导剂，与其联用的抗生素疗效会有不同程度的降低。
